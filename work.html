World 01
mGrant
Both sides of the money.
mGrant (Donor + CSR)

The grant-maker's side: RFP → application → grant → disbursement → compliance → impact. I built the compliance layer for India's Section 135 CSR mandate: statutory obligation calculation, budget attribution, year-end freeze, and the full set of statutory reports. Multi-year and lean grant pipelines. A four-tier results framework: input → output → outcome → impact.

mGrant NuO

The grantee's side: an NGO managing incoming funds, sub-grants to implementing partners, FCRA-aware fund tracking, logical-framework reporting, and periodic utilisation reports back to donors.

100+ features across 70+ tenant setups · 50+ sprints as product owner. A large rural-development foundation runs a ₹540 Cr, 239-grant portfolio on the platform, with 50+ board reports. I translate regulation, Section 135, FCRA, into product behaviour, and own security and compliance as Data Privacy Officer.

Frappe Mobile (open source)

Product manager for an open-source Flutter-on-Frappe mobile platform: a client SDK (metadata-driven dynamic forms, offline-first SQLite sync) and a server app (mobile auth, OTP, force-update). Built so field apps work offline by default.

Frappe Helpdesk ticketing

Internal delivery toolkit

Built a Claude Code plugin that encodes the whole Frappe build methodology, skills, agents, and safety guardrails, so the team ships consistently.

I read and review across the stack, data models, the security layer, the framework itself, not just configuration.
World 04
AI-assisted building
Rebuilt how delivery works.
Builder Protocol

A three-role, eight-phase AI-assisted delivery model, the Architect defines and decides, an AI tool builds, a human reviews before ship. It replaced a six-specialist SDLC and runs live across 5+ client builds. A memory layer keeps context, security rules, and decisions persistent across sessions.

Proddy

A personal AI agent for product work: triage, minutes, specs, follow-ups. github.com/Goofbol/proddy

AI-enablement program

Founded and ran an internal program teaching domain experts, not engineers, to ship real products with agentic tools, from vibe-coding to CLI, hooks, agent skills, and MCP.

5+ client builds running live on the Builder Protocol model. The Architect role is a product call, not a technical one: deciding what gets built, what does not, and why.
